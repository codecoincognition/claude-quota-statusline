I Built a Free Tool to Show Your Claude Code Quota Usage in the Status Bar

If you use Claude Code with a Pro or Max subscription on Mac, you've probably hit that moment mid-session: how much of my quota have I actually burned through?

You could type /usage inside a session and check. But that breaks your flow. What if the answer was just… always there?

What it looks like

A single line at the bottom of your Claude Code terminal:

⟡ 5h: 25% │ 7d: 21%

That's it. Two numbers — how much of your 5-hour rolling window and 7-day weekly quota you've used. Updated automatically after every Claude response.

The colors shift as you approach your limit:

  • Green — under 80% used, you're good
  • Yellow — 80–94% used, start wrapping up
  • Red — 95%+ used, almost out

How it works

Claude Code has a statusLine feature — it pipes JSON metadata to a configured script after every assistant response. That metadata already includes your quota usage percentages. No extra API calls. Zero quota cost.

The tool is a single shell script that reads that JSON via jq and formats it with color codes. The installer copies the script to ~/.claude/ and patches your settings.json — nothing else gets touched.

Install in 10 seconds

macOS only. One command:

curl -fsSL https://raw.githubusercontent.com/codecoincognition/claude-quota-statusline/main/install.sh | bash

Then restart Claude Code. That's it.

If you don't have jq installed, the installer handles it automatically via Homebrew. If you don't have Homebrew either, it'll tell you what to do.

Uninstall

Just as easy:

bash <(curl -fsSL https://raw.githubusercontent.com/codecoincognition/claude-quota-statusline/main/uninstall.sh)

Why I built this

I spend a lot of my day inside Claude Code. I kept running into rate limits without realizing I was close. Having the usage percentage visible at all times changed how I pace my sessions — I batch lighter tasks when I'm running high and save the heavy lifting for when I have headroom.

It's a small quality-of-life improvement, but the kind that compounds over every session.
